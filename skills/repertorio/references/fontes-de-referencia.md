# Onde garimpar referência

Fluxo: captura → salva com link → agrupa por família visual → dá nome → reusa em todo build.

| Fonte | Pra quê |
|---|---|
| godly.design | sites com melhor design da web; tire print e peça "combine a sensação" |
| land-book.com / lapa.ninja / onepagelove.com | landing pages por categoria |
| siteinspire.com / minimal.gallery | sites calmos, editoriais |
| awwwards.com | movimento e 3D (cuidado: muito é inviável pra cliente local) |
| mobbin.com / refero.design | telas reais de apps e fluxos |
| dribbble.com | ordene por popular; bom pra hero e composição, ruim pra realidade |
| pinterest | heros e composições que você não conseguiria descrever em prompt |
| X/Twitter (designers postando UI em andamento) | tendências antes de virarem template |
| transitions.dev | animações de UI copia-e-cola + skill de transições |
| animos.app | transformar prints em vídeo de lançamento no navegador |
| deck.gallery | layouts de deck reais |
| 21st.dev / originkit.dev / magicui.design | componentes prontos (via MCP) |
| fonts.google.com (filtrar por "feeling") | substituir Inter |

## Regras éticas
- Referência é sensação (ritmo, proporção, temperatura de cor), não cópia de layout de outro designer.
- Nunca reproduza logo, marca, ilustração ou personagem de terceiros.
- Fotos do cliente: só do Insta/Maps do próprio cliente e com aprovação antes de publicar.
