# Pool de fontes (Google Fonts) por categoria

Antes de escolher: `node "${CLAUDE_PLUGIN_ROOT}/scripts/historico.mjs" fontes` lista as display usadas nos últimos projetos. Não repita nenhuma. No leque, cada variante pega uma categoria diferente.

**Cemitério (não usar como display sem prova no `dna.md`):** Fraunces, Instrument Serif, Playfair Display, DM Serif Display, Cormorant (Garamond), Libre Caslon, Gloock, Young Serif, Inter, Roboto, Poppins, Montserrat, Space Grotesk, Syne. São as que todo modelo escolhe.

| Categoria | Display (título) | Texto |
|---|---|---|
| Grotesk / neo-grotesk | Familjen Grotesk, Schibsted Grotesk, Hanken Grotesk, Instrument Sans, Funnel Display, Host Grotesk | Geist, Figtree, Onest, Public Sans |
| Humanista / amigável | Nunito (só display pesado), Lexend, Outfit, Gabarito, Bricolage Grotesque | Atkinson Hyperlegible, Source Sans 3, Rubik |
| Display condensada | Anton, Oswald, Big Shoulders Display, Barlow Condensed, Sofia Sans Extra Condensed, Antonio | Barlow, Archivo |
| Serif de texto (sóbria) | Newsreader, Literata, Source Serif 4, Crimson Pro, Spectral, Petrona | Literata, Source Serif 4 |
| Slab / editorial firme | Zilla Slab, Roboto Slab (pesos altos), Arvo, Bitter | Bitter, IBM Plex Sans |
| Mono / técnica | JetBrains Mono, IBM Plex Mono, Space Mono, DM Mono, Martian Mono | IBM Plex Sans, Geist |
| Expressiva (1 por projeto, no máximo) | Unbounded, Dela Gothic One, Climate Crisis, Rubik Mono One, Bagel Fat One, Chango | qualquer neutra acima |

Escolha pela VOZ do `voz.md` e pelo público, não pela "elegância": escola infantil pede humanista/arredondada; barbearia pede condensada ou slab; advocacia pede serif de texto sóbria; academia pede condensada pesada.
