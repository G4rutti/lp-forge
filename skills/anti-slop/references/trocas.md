# Trocas rápidas: o que a IA faz → o que fazer

| Tell | Troca |
|---|---|
| Inter em tudo | Display com caráter (Fraunces, Instrument Serif, PP Editorial*, Bricolage Grotesque, Space Grotesk só se for tech, Syne, DM Serif Display, Gloock) + texto neutro bom (Geist, Manrope, Public Sans, IBM Plex Sans, Satoshi*) |
| Roxo→azul no hero | Fundo chapado off-white ou quase-preto tingido; cor entra em UMA palavra da headline ou num bloco |
| Badge "✨ Novo" acima do H1 | Linha de contexto em versalete pequeno: bairro, horário, "Desde 2016" (se for verdade) |
| 3 cards de features com ícone | Lista numerada tipográfica grande; ou bento com 1 célula dominante + foto real |
| Depoimentos em carrossel de cards | 1 citação real gigante em tela cheia, nome + bairro, link pras avaliações do Google |
| Mockup de dashboard falso | Foto real do lugar/equipe/resultado; ou demo inline do serviço (ex.: simulador de horário) |
| "Saiba mais" | Verbo + objeto + canal: "Agendar avaliação no WhatsApp" |
| Sombra grande difusa em card | Borda 1px de neutro tingido; ou nenhuma divisão, só espaço |
| `rounded-2xl` em tudo | Escolha UM raio do sistema (0, 4, 8 ou pill) e use com propósito |
| Scroll-reveal em todo bloco | 1 coreografia de entrada no hero + 1 momento de movimento no meio; o resto parado |
| Ícones de cores variadas em quadradinhos | SVG monoline `currentColor`, mesmo peso, sem fundo |
| Paleta Tailwind default (`slate`, `indigo`) | Tokens OKLCH próprios: neutros com chroma 0.005-0.02 na matiz do acento |
| Preto puro `#000` / branco puro `#fff` | `oklch(0.16 0.01 H)` / `oklch(0.98 0.008 H)` |
| Footer com 4 colunas de links mortos | Footer útil: endereço com mapa, horário, WhatsApp, Insta, CNPJ se tiver |

*fontes pagas/licenciadas: só se o cliente tiver licença; senão use a alternativa do Google Fonts.
